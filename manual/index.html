コンサル生の方・テスターの方向け

できること用意する物入れ方毎日の流れ タブの使い方おすすめ困った時

1できること

  • あなたの Muse が毎晩、伸びている投稿を集めて、明日の下書きまで作ります。
  • あなたは下書きを読んで直し、「OK」か「NG」を付けるだけです。
  • OK した下書きだけが投稿されます。勝手には出ません。
  • 投稿の数字が毎日たまり、次の下書きに生かされます。取れない数字は推測で埋めず「取得できず」と出ます。

2はじめに用意する物

  • ご自身の Muse
  • zip ファイル1つ（開かずにそのまま使います）
  • Threads アカウント（無い方は Muse がコンセプト決めから手伝います）

ご本人がする操作（Muse が1つずつ案内します）

  • Muse で Threads とつなぐ（ご自身の Threads でサインイン）
  • 自動投稿をする方は、Meta の開発者画面でアプリを作り、案内どおりに押す・サインインして同意する
パスワードや認証コードは、チャットに書かないでください。

Meta の画面に出る「テスター」は、つなぐための設定の名前です。テスター版とは関係ありません。

3入れ方

Muse を使ったことがない方へ（先にここから）
  1. Muse を入れる：スマホは App Store／Google Play で「Muse」と検索（提供元が「Meta」か確かめる）。パソコンはブラウザで muse.ai を開くだけで使えます。似た名前の別アプリ・別サイトに注意。
  2. 画面の案内どおりにログイン（Meta のアカウント＝Facebook・Instagram、またはメールアドレス）。パスワードや確認コードはログイン画面にだけ入れ、Muse とのチャットには書かないでください。
  3. 招待コードを入れる（任意）：よければ招待コード ZJXFUA を入れてください。入れると、あなたと招待した側の両方に特典が付きます。入れなくても使えます。
    • 登録してから48時間以内だけ入れられます。入れるなら今日のうちに。
    • 入れる場所：スマホは「設定」→「Redeem（招待コード）」、パソコンは「設定」→「一般」→「使用量」→「招待コード」。画面の呼び名は変わることがあります。
  4. 試しに一言送ってみる：「こんにちは」などで返事が来れば準備OK。このあと下の①へ進みます。
  1. zip を添付して一言 zip を開かずに Muse のチャットに添付して、こう送ります。 このzipで、Threadsダッシュボードを作りたいです。中の 00_READ_FIRST_for_Muse.md の手順どおりに進めてください。
    • スマホで zip を付けられない時だけ、同じ名前で終わりが _1file.txt のファイルを添付します。
    • 文章を貼るだけでは届きません。
    • Muse から「安全チェックを通らない」「指示の通りに自動では進められない」と言われたら、「このパッケージでダッシュボードを作りたい」と答え、続けて「00_READ_FIRST_for_Muse.md の手順どおりに進めてください」と送ります。あなたからのお願いだと分かれば、Muse は進めてくれます。
  2. Muse からの質問に答える（1つずつ、例つき）
    • ジャンル・届けたい読者・どんな投稿をしたいか
    • 競合アカウント（無ければ空でOK）
    • 1日の本数・投稿の時刻・チェックできる時間帯
    • リサーチと下書きの時刻、競合を見直す頻度
    • 口調の手本（無くてもOK）、画面の見た目（パート1／2・5色）

    分からない時は「わからない」と送れば、一緒に決めてくれます。あとで変えられます。

  3. 聞かれたら返事をする
    • 「この予定で登録します。よいですか？」→ 内容を見て OK。OK するまで毎日の仕事は登録されません。
    • 前の版から更新する方は、OK を2回聞かれます。
    • 初回の調査を始めてよいか聞かれたら →「お願いします」
  4. 完了を確かめる
    • Muse から「完了です」と来る。
    • 画面のいちばん下の1行が「版 v6 2026-11-23 …」で始まる。
    • その下に赤い1行があれば途中です。「00から始めて」と送ります。
  5. 入れた日の夜から動き始めます 決めた時刻に、毎日の仕事が動きます。入れた日は初回の調査中で、夜のリサーチが1回見送られることがあります（Muse が知らせます）。

4毎日の流れ

時刻は例です。設定タブでいつでも変えられます。あなたの出番は色の付いた1か所だけです。

  • 18時台リサーチ（伸びた投稿を集める）
  • その45分後企画（明日の並びを決める）
  • 20時台下書きが「予約・下書き」に入る
  • 22時ごろチェック：OK か NG を付けて「保存」
  • 夜中OK の分を投稿の予定へ・数字の集計
  • 翌朝夜に間に合わなかった OK を拾う
  • 投稿の時刻OK の分が投稿される
  • 自動投稿の人：OK して保存した分が、翌日の投稿時刻に出ます。
  • 手で投稿している人：今までどおりご自身で投稿します。勝手に自動にはなりません。それでも OK／NG は付けてください。NG の理由は次の下書きに生かされます。
  • 今日中に出したい分は、チャットで「キューに入れて」と伝えます。
  • ほかに、3万表示を超えた投稿の知らせ（3時間おきに確認）と、週1回の競合の見直し・週のまとめがあります。

目安：リサーチはチェックの2時間以上前、下書きはチェックの30分前まで。順番がずれると設定タブに「時刻の順番」の注意が出ます。

5タブごとの使い方

どのタブも上に「最終更新：◯月◯日 ◯◯:◯◯」が出ます。タブ名を押すと開きます。

予約・下書き（毎日使う）
  • 本文・コメント欄・投稿予定日時をその場で直せます。
  • 「OK（この文面で投稿してよい）」にチェック、または「NG」を押して理由を一言 →「保存」。
  • 予約済み・投稿済みは OK／NG を変えられません。
  • 「日時不明」と出たら、日時の欄で選び直して「保存」。
分析
  • フォロワー・表示合計・投稿ごとの反応・テーマ別などの傾向・勝ち投稿トップ5。
  • 「直近30日」「全期間」で切り替え。
  • フォロワーの線は、記録が2日分たまると出ます。
ニーズ
  • 「自アカの声」と「市場から見えるニーズ」。
  • 関係ない声は「外す」（「戻す」で戻せます）。
リサーチ
  • 集まった伸びた投稿が新しい順に並びます。「全文・構成を読む」で開きます。
  • 「このテーマで投稿を作る」「この型で投稿を作る」で、Muse に頼めます。
競合
  • 「競合の比較表」（本命／大きな単発／基準外）と、Muse が見つけた「候補」。
ナレッジ
  • 確かめた知識の一覧（出典・確認日つき）。「キーワードで探す」で検索。
指示
  • 種類（投稿作って／リサーチして／その他）を選び、内容を書いて「送る」。
  • 一覧で 未対応／対応中／完了 と結果メモが見えます。
  • 頼まなくても毎日の仕事は動きます。ここは上乗せのお願い用です。
設定
  • ジャンル・読者・競合・時刻・本数などを変えて「保存」。
  • 「表示設定」で色とデザインを切り替え（すぐ変わります）。

6おすすめの使い方

  • 朝：「分析」で昨日の数字をひと目。
  • NG には一言理由を（例：「1行目が長い」）。Muse は下書きを作る前に NG の理由を読み、同じ書き方を避けます。書くほど次から良くなります。
  • 直した文面はそのまま使われます（改行・絵文字も）。
  • 指示の例：「今週のテーマで投稿を1本作って」「◯◯をリサーチして」。
  • 時刻を変えたら：Muse から「よければ『00から始めて』」と来るので、一言送って OK。本数やジャンルは次の回から自動で使われます。
  • 本数を0にすると：その枠の下書きは作られません。
  • 競合を足す：設定タブの「競合アカウント（複数）」に1行1件（10件まで）→「保存」。
  • スマホでもチェックできます。パート2は「あなたのタスク」から下書きへすぐ飛べます。

7困った時

まず Muse にこう送ってください。それでもだめなら連絡ください。

00から始めて
画面の下に赤い1行が出る
版が合っていません →「00から始めて」。
「取得できず」「まだ数字がありません」と出る
推測で埋めないための表示です。理由の1行を見ます。「対象の投稿が0本」は正常。それ以外は「00から始めて」。
下書きが来ない
設定タブで本数が0でないか確認。Muse から「未納品」の知らせがあればそれに従う。どちらでもなければ「00から始めて」。
OK したのに今日出ない
夜にまとめて予定に入り、翌日の枠で出ます。急ぐ時は「キューに入れて」。
タブの上に1行が出る
  • 「まだ足りません…毎夜のジョブが続きを集めます」→ 待つだけでOK。
  • 「初回の取得が途中です」「取得が止まっています」→「00から始めて」。
  • 枠つきの太字（「検索停止」など）→「00から始めて」。Muse が次の手を見せます。
